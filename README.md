## A tua liga, com outra vida

**Peladinhas Cards** dá continuidade aos jogos de uma comunidade de futebol: reunir o plantel, organizar equipas, reconhecer boas performances e acompanhar a evolução de cada jogador.

A carta é o centro dessa identidade. A fotografia, a posição, os atributos e a raridade contam uma história construída pela comunidade e pelo que acontece em campo. Cada semana guarda uma nova etapa.

## Cada jogo conta

**Criar o perfil → conhecer a comunidade → entrar em campo → evoluir → guardar a história.**

As avaliações estabelecem a base da carta. Os jogos acrescentam performance e progressão. Os eventos reconhecem conquistas. O histórico preserva as semanas que ficaram para trás.

O produto usa HTML, CSS e JavaScript nativo, com Firebase para contas, dados, fotografias e processamento. A PWA mantém a mesma liga entre o browser e a aplicação instalada.
